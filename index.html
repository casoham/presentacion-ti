Así está hecho hoy: aplicación en React con Vite y TypeScript; API en Node con sesiones HttpOnly por rol (estudiante y docente) y la calificación se hace en el servidor; base de datos Turso con migraciones, y SQLite para desarrollo. Acceso con Google y Microsoft Entra ID. Cada cambio pasa por lint, tipos, pruebas y accesibilidad en GitHub Actions.
